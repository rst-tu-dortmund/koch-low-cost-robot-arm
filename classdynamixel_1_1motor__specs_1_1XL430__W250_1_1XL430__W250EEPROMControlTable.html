Detailed Description

EEPROM control-table fields for the Dynamixel XL430-W250.

Each attribute is a ControlField with (address, size and initial value). These fields reside in non-volatile memory and typically require torque-off to modify.

Note
Assumption: addresses and defaults follow the Robotis XL430-W250 e-Manual.
