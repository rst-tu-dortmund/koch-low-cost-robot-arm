Detailed Description

Utilities for Dynamixel unit conversion and little-endian packing helpers.

Provide consistent conversions between logical units (rad, deg, rpm, rad/s) and Dynamixel "DXL" ticks, plus small helpers for signed/unsigned 32-bit coercion and struct packing.
