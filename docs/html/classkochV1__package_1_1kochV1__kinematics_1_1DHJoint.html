Detailed Description

Denavit-Hartenberg joint/link parameters.

Stores standard (a, alpha, d, theta) along with joint limits and offsets. For revolute joints theta is the variable; for prismatic joints d is the variable.

Note
Angles are in radians; lengths are in meters.
