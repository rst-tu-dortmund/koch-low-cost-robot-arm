Detailed Description

Lightweight bus wrapper to open/close the port and access Dynamixel registers.

Provides context-manager semantics, helpers to read/write registers via ControlField descriptors, and support for constructing and caching SyncGroup instances.

Note
Assumption: A single physical port is used; _get_active_port searches /dev for entries containing ttyUSB or ttyACM when no port name is provided.
