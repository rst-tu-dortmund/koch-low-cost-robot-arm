Detailed Description

Batch read/write wrapper for a single control-table field across multiple motors.

Creates paired GroupSyncWrite and GroupSyncRead handles for the same address and data length. Each provided motor ID is registered for both read and write operations.

Note
Uses little-endian, signed representation when writing multi-byte values.
