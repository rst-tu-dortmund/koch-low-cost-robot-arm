Detailed Description

High-level interface for commanding the simulated Koch V1.1 robot arm.

Exposes convenience methods to set joint angles/velocities, compute and execute IK targets, and read back the joint configuration and end-effector transform.

Set joint velocities for the first 5 joints (velocity control).

Currently in a development state. It works with high velocities but not with low velocities since the simulation errors accumulate fast.

Parameters
