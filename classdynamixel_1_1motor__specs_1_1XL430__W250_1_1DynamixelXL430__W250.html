Detailed Description

Per-motor data and shared specs for the model XL430-W250.

Stores the device ID, assembly-specific home position, and physical position limits (in DXL ticks). Also exposes class attributes for the model's EEPROM/RAM control tables, tick-per-revolution constant, and operating-mode enum.

Note
logical_position_limits are derived as physical_position_limits - physical_home_position.
