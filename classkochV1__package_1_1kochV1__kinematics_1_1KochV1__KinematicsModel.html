Detailed Description

Kinematics model (FK, IK, Jacobian) for the robot arm Koch V1.1.

Defines a 5-DOF DH chain; Provides analytical FK/IK and symbolic Jacobian compiled to NumPy.

Build an SE3 transform from Cartesian coordinates and two orientation angles.

Constructs orthonormal axes with Z aligned by psi about the global Z, then rotates the local XY frame by phi about the intermediate Y to form the final rotation.

Parameters
xfloat Position X in meters.
yfloat Position Y in meters.
zfloat Position Z in meters.
psifloat Elevation of the end-effector Z-axis above the horizontal plane (radians).
phifloat Rotation about the end-effector Z-axis (radians).
Returns
SE3 Homogeneous transform in the base frame.
Note
Assumption: x == 0 implies theta1 = 0 for the base yaw computation.
