Detailed Description

Protocol for Dynamixel motor models exposing control-table classes.

Implementations provide class attributes EEPROM and RAM (namespaces of ControlFields) and an id identifying the device on the bus.

Note
This is a typing protocol; it specifies the expected interface but does not implement it.
