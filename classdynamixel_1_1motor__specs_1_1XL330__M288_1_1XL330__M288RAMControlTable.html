Detailed Description

RAM control-table fields for the Dynamixel XL330-M288.

Each attribute is a ControlField with (address, size, initial value at power-on). These fields reside in volatile memory and can be changed while torque is enabled, subject to device rules.

Note
Assumption: addresses and defaults follow the Robotis XL330-M288 e-Manual.
